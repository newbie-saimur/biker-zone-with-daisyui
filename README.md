# Biker Zone with DaisyUI

🔗 **Live Demo:** [https://newbie-saimur.github.io/biker-zone-with-daisyui/](https://newbie-saimur.github.io/biker-zone-with-daisyui/)

A modern, responsive motorcycle/bike showcase website built with HTML5, TailwindCSS, and DaisyUI. The project features a clean and attractive design with smooth carousel animations, bike showcases, customer testimonials, and more.

## 🎯 Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Interactive Carousel** - Hero section with multiple bike slides
- **Featured Bikes Section** - Showcase of popular bike models
- **Latest Bikes Collection** - Grid layout of newest bike offerings
- **Customer Reviews** - Testimonial section with ratings
- **FAQ Section** - Frequently asked questions with collapsible answers
- **Mobile-First Design** - Optimized for mobile devices with desktop enhancements

## 🛠️ Technologies Used

- **HTML5** - Semantic markup structure
- **TailwindCSS** - Utility-first CSS framework for styling
- **DaisyUI** - TailwindCSS component library for pre-built components
- **Google Fonts** - Poppins font family for typography
- **CSS3** - Custom styles and animations

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Basic understanding of HTML, CSS, and TailwindCSS (for modifications)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/newbie-saimur/biker-zone-with-daisyui.git
   ```

2. **Navigate to the project directory**
   ```bash
   cd biker-zone-with-daisyui
   ```

3. **Open in browser**
   - Simply open the `index.html` file in your preferred web browser
   - Or use a local development server like Live Server (VS Code extension)

### Development Setup

For development with live reload:

1. **Install Live Server** (VS Code Extension) or use any local server
2. **Right-click** on `index.html` and select "Open with Live Server"
3. **Start editing** - changes will be reflected automatically

## 🎨 Customization

### Colors
The project uses a custom color scheme defined in TailwindCSS:
- Primary: `#E76F51` (Orange-red)
- Text: `#18191F` (Dark gray)
- Secondary text: `#6C6C6C` (Gray)
- Accent: `#23A6F0` (Blue)

### Fonts
- **Primary Font:** Poppins (Google Fonts)
- Loaded via CDN for optimal performance

### Components
The project leverages DaisyUI components:
- Navbar with responsive hamburger menu
- Carousel with navigation controls
- Cards for bike showcases
- Rating components for reviews
- Collapse components for FAQ

## 📱 Responsive Breakpoints

- **Mobile:** Default styles (< 768px)
- **Tablet:** `md:` prefix (≥ 768px)
- **Desktop:** `lg:` prefix (≥ 1024px)
